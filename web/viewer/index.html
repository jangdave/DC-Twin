        로컬 계산 서버에 연결

        이 컴퓨터에서 계산 서버를 먼저 실행하세요. 서버가 계산한 값이 이 화면에 실시간으로 나오고, 슬라이더 조작이 서버로 전달됩니다.

        cd sim/sensors
uv run --python 3.13 --extra serve python -m dct_sensors.serve --manifest ../out/sensor_manifest.json --solver l0

        solver를 l2로 바꾸면 보정 모델(AI)의 90% 구간과 신뢰 막대도 나옵니다(Warp 환경 필요). 이 컴퓨터의 ws://와 wss://만 연결할 수 있습니다.

        서버가 토큰을 요구할 때만 넣는다(이 컴퓨터의 서버는 보통 필요 없다). 토큰은 이 화면의 메모리에만 있고 저장하지 않으며 주소에 붙지 않는다. 서버를 처음 열 때 `--token`으로 정한다.

        보는 방법

        시뮬레이션 값은 시각화 목적이며 공학적 정확성을 주장하지 않는다. 가상 시설이다.

        • 랙 앞면의 색은 선택한 값이다. 온도는 18도(파랑)에서 35도(빨강)까지 변한다.
        • 랙 위의 막대는 AI 대리 모델 보정값의 믿을 수 있는 정도다. 막대가 짧을수록 90% 구간이 넓다(불확실하다).
        • 테두리는 알람이다. 노랑은 주의, 빨강(깜박임)은 위험이다.
        • 왼쪽 메뉴(서버실 안에서만 보임)는 하나만 눌린다. 모니터링은 현장 센서 값과 알람(지금은 미리 만든 기록 값), 시뮬레이션은 미리 계산해 둔 상태와 시나리오(이상 상황, 급기 온도, 부하)를 골라 보고 비교, 간이 계산은 이 브라우저가 간단한 모델로 바로 계산하며 슬라이더로 조작, CCTV는 구역마다 설치한 가상 카메라 7대다. 팬, 전력, 공급 온도를 직접 바꿔 자세히 계산하려면 서버에 연결한다.
        • 오른쪽 패널은 탭으로 나뉜다. 요약(시나리오와 상황), 장비(고른 랙이나 CRAC), 알람(숫자는 지금 이상인 센서 수, 목록은 지나간 변화까지 포함, 누르면 그 장비로 이동). 시뮬레이션에서는 에너지·용량(전력, 기준 비교)과 이상 대비(대응 순서)가, 간이 계산과 서버에서는 조작(슬라이더)도 더 나온다.
        • 외관에서 건물을 누르거나 Enter를 누르면 홀로 들어간다. 홀에서 Esc나 "외관으로" 단추로 돌아온다.
        • 화면 나눠 비교: 시뮬레이션 메뉴의 에너지·용량 탭에서 "지금을 기준으로 저장"을 누르고 시나리오를 바꾼 뒤 "화면 나눠 비교"를 누르면, 3D 화면의 왼쪽은 저장한 기준 색, 오른쪽은 지금 색으로 나뉜다. 가운데 선을 끌어 경계를 옮긴다(랙 색만 비교하며 알람 표시는 지금 값이다).
        • 조작: 왼쪽 버튼 하나로 한다. 끌면 데이터센터 중심을 기준으로 돌고, 짧게 누르면 랙을 선택해 상세를 본다. 휠로 확대한다(자유 이동은 없다. 휴대폰은 한 손가락 끌기로 돌고 두 손가락으로 확대한다). 스페이스바는 재생과 정지, 좌우 화살표는 5초 이동(Shift는 30초), 캔버스에서 방향키는 랙 이동이다.

        화질

        바꾸면 화면을 다시 불러온다. 자동은 기기를 보고 고르고, 프레임이 낮으면 한 단계 낮춘다. 보통은 FHD(1920x1080) 화소 수에 맞춰 그리고, 보통 이상은 표시등과 켜진 창이 은은히 번지며 높음은 접촉 그림자도 쓴다.

        신뢰 등급

          녹화 재생은 센서 생성기가 미리 만든 값을 돌려 보는 것이라 실시간이 아니다. 로컬 게이트웨이가 있으면 주소 끝에 ?live=ws://127.0.0.1:8080/ws를 붙여 실시간으로 볼 수 있다.
