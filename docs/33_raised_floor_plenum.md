# 33. 이중 바닥과 바닥 아래 공간(플레넘)

- 상태: 초안 (2026-11-11). A단계(장면과 우리 계산), B단계(OpenFOAM 비교)까지 했다. **기본값은 꺼짐**이다.
- 목적: 바닥 급기 방식에서 공조기가 찬 공기를 바닥 아래로 불어 넣고, 그 압력으로 차가운 통로의 천공 타일에서 찬 공기가 올라오는 순환을 장면과 계산에 넣는다. 지금까지는 급기구 칸에서 찬 공기가 바로 생겨났다(`docs/decisions/ADR-009` "바닥 아래 공기 흐름은 처음에는 단순하게").
- 관련: [ADR-009](decisions/ADR-009-hall-layout-and-cooling.md), [32 정확도 검증](32_kit_accuracy_verification.md), [31 세 메뉴](31_monitoring_simulation_quickcalc.md)
- 시각화 목적이며 공학적 정확성을 주장하지 않는다.

## 1. 사용자 요청 (2026-11-10)

"바닥 아래 층에서도 차가운 공기가 순환해야 하는 거 아닌지 확인" → 확인 결과 장면, 우리 계산, OpenFOAM 모두 바닥 아래 공간이 없었다. "전부 진행"으로 추가하기로 했다.

## 2. 정한 값 (근거 없는 가상 값)

| 항목 | 값 | 비고 |
|---|---|---|
| 바닥 아래 공간 깊이 | 60 cm | 흔히 0.6~1.2 m라는 업계 자료가 있지만 표준값을 확인하지 못했다(ADR-009) |
| 바닥판 두께 | 20 cm | 기존 `floor_thickness` 그대로 |
| 천공 타일 열린 비율 | 25 % | 흔히 쓰는 값으로 알려져 있으나 확인하지 않았다 |
| 공조기 송풍 | 아래로(하향) | 공조기 바로 아래 바닥 아래 공간 맨 윗층에 자기 회수량만큼 불어 넣는다 |

설정: `usd/scenes/hall01.config.json`의 `raised_floor`(`enabled`, `plenum_depth`, `tile_open_ratio`). 켜면 `build_scene.py`가 홀 prim에 `dct:plenumDepthCm`, `dct:floorThicknessCm`, `dct:tileOpenRatio`를 쓰고 `Shell/Plenum`(보기용 상자, guide)을 만든다.

## 3. 우리 계산의 바뀐 점 (`hall60_sim.py`)

- 격자를 아래로 (깊이 + 바닥판) = 8칸 늘린다. 계산 좌표는 z를 80 cm 올리고, 센서 앵커도 같은 만큼 올려 읽는다(`Layout.z_off_cm`).
- 바닥판 층은 막고 천공 타일 자리만 연다. 타일 칸의 통과 쉬움(`sigma`)을 열린 비율(0.25)로 낮춘다. 그래서 타일마다 나오는 양이 압력에 따라 달라진다.
- 급기구 칸에서 공기가 생겨나지 않는다. 대신 공조기 아래 바닥 아래 공간에서 생겨난다(급기 온도). 회수구 높이도 바닥 윗면 기준으로 올린다(처음에 빠뜨려 흐름 풀이가 실패했다).

| 조건 | 이류 | 설명 안 되는 열 수지 차이 | 입구 평균 / 최고 | (바닥 아래 공간 없을 때 최고, fv) |

| 정상 | fv | +0.16 % | 18.00 / 18.00 | 18.00 |
| CRAC_02 정지 | fv | −0.03 % | 18.42 / **23.61** | 20.26 |

| 정상 | MacCormack(기존) | −12.4 % | 18.84 / 19.43 | |

- **이중 바닥에서는 fv를 써야 한다.** 기존 방식은 열을 5~12 % 만든다.
- 고장 조건에서 더 뜨겁다(최고 +3.3도). 공조기가 꺼지면 바닥 아래 공기가 줄고 분포가 바뀌어 그 통로의 타일 바람이 약해진다.

| 조건 | 합계 | 타일 최소 / 최대 | 통로별 합 | 1번 통로 타일(줄 끝 → 가운데 → 줄 끝) |
|---|---|---|---|---|
| 정상 | 57.6 | 1.40 / 2.92 | 19.3, 19.0, 19.3 | 2.92, 2.05, 1.70, 1.53, 1.45, 1.45, 1.53, 1.70, 2.05, 2.92 |
| CRAC_02 정지 | 48.0 | 1.14 / 2.77 | 14.9, 15.4, 17.7 | 1.71 … 1.14 … 2.61 |

- **한계(중요):** 우리 흐름은 퍼텐셜 흐름이라 공조기 가까운 타일에 바람이 **많이** 나온다. 실제 이중 바닥에서는 공조기 가까이 바닥 아래 공기가 빨라 압력이 낮아져 오히려 **적게** 나오거나 거꾸로 빨려 들어가는 일이 알려져 있다(관성 효과). 이 차이는 OpenFOAM(B단계)으로 확인해야 한다.

## 5. B단계: OpenFOAM과 비교 (2026-11-11)

OpenFOAM 사례에도 이중 바닥을 넣었다(`gen_case.py`: 바닥판 층은 막고 타일 칸만 열어 Forchheimer 저항(K ≈ 30, 열린 비율 25 %), 공조기 아래 바닥판 밑면을 급기 입구로, 회수구와 센서 높이를 바닥 윗면 기준으로). 칸 66.7만 개, 16코어. 이중 바닥이 없을 때 만든 사례는 예전과 같다(사례 파일을 비교해 메타 정보 외 차이 없음).

| 사례 | 반복 | 수렴 | 시간 | 열 수지(랙 600 kW → 회수) | 랙 입구 평균 / 최고 |
|---|---|---|---|---|---|
| 정상 | 3000(한도) | 압력 잔차 7e-4로 기준(1e-4) 못 맞춤, 온도 3e-7 | 21분 | 599.4 kW | 19.04 / 20.56 |
| CRAC_02 정지 | 2356 | 수렴 | 17분 | 596.3 kW | 20.49 / 27.99 |
| 같은 통로 2대 정지 | 1261 | 수렴 | 9분 | 597.5 kW | 23.33 / 31.30 |

**타일마다 올라오는 바람** (m³/s, 1번 차가운 통로 10장)

| | OpenFOAM | 우리(타일 = 열린 비율 0.25) | 우리(보정 0.002) |
|---|---|---|---|
| 정상 | 1.83~1.94(거의 고름) | 2.92 … 1.45 … 2.92 | 고름(타일 RMSE 0.05) |
| 2대 정지, 통로별 합 | 12.8, 12.4, 12.6 | 10.6, 11.7, 16.1 | 12.6, 12.8, 13.0 |

- **OpenFOAM에서는 타일 바람이 거의 고르다.** 타일 저항이 커서 바닥 아래 압력이 고르게 되기 때문이다. 공조기 가까운 타일이 약해지는 현상도 이 조건(깊이 60 cm, 타일 25 %)에서는 거의 없었다(역류 타일 0).
- 우리 계산은 타일 저항을 열린 비율로 두면 너무 약했다. **타일 통과 쉬움을 0.002로 보정**했다(`hall60_sim.TILE_SIGMA`, 위 3개 사례에 맞춘 값). 4장의 "고장 때 최고 +3.3도"는 이 약한 저항 때문에 생긴 값이라 **틀린 결론이었다.** 보정 뒤 우리 계산의 최고 온도는 바닥 아래 공간이 없을 때와 거의 같다(CRAC_02 정지 20.3도, 2대 정지 29.5도).

**랙 입구 온도, OpenFOAM(이중 바닥) 대비** (RMSE / 최대 차이, 도)

| 사례 | 우리 흐름 + fv | 우리 흐름 + MacCormack | **OpenFOAM 흐름 + fv + 다공질 랙** |
|---|---|---|---|
| 정상 | 1.23 / 2.55 | 0.61 / 1.44 | **0.10 / 0.30** |
| CRAC_02 정지 | 3.38 / 9.41 | 2.32 / 7.98 | **0.47 / 1.37** |
| 같은 통로 2대 정지 | 2.79 / 5.91 | 4.78 / 10.82 | **0.55 / 1.21** |

- 이중 바닥이 있어도 **정확한 시뮬레이션의 구성(OpenFOAM 흐름 + 우리 온도 계산 + 다공질 랙)은 OpenFOAM을 0.1~0.55도로 다시 낸다.** 
- 우리 흐름(퍼텐셜)만으로는 이중 바닥이 없을 때와 같은 수준으로 틀린다(고장 조건 RMSE 2.8~3.4도). 큰 오차의 원인이 흐름 모델이라는 V4 결론이 그대로다.
- OpenFOAM끼리 보면 이중 바닥의 영향은 작다(최고 온도: 정상 19.89 → 20.56, CRAC_02 정지 28.27 → 27.99, 2대 정지 30.87 → 31.30도). 이 조건에서는 타일 바람이 고르기 때문이다.
- 웹 흐름장과 화면의 바닥 아래 보기는 기본값을 켤 때(C단계) 함께 만든다. 지금 웹은 이중 바닥이 없는 장면을 보여 준다.
