# 26. 자연스러운 도심과 외관 이미지 효과

- 상태: 채택 (2026-11-03)
- 목적: 주변 건물이 모두 같은 상자로 보이던 도심을 다양하고 자연스럽게 만들고, 이미지(그림)와 화면 효과로 외관 품질을 올린다.
- 관련: [23 도심과 화질](23_web_city_and_quality.md), [22 외관과 공기 흐름](22_web_exterior_airflow_spec.md)
- 표기: 가상의 도시다. 실제 지역, 건물, 상표를 본뜨지 않았다. 외부 이미지와 에셋은 쓰지 않고 그림도 코드로 그린다.

## 1. 바뀐 점

| 항목 | 전(23) | 후 |
|---|---|---|
| 필지 | 블록을 2x2로 똑같이 나눔 | 블록을 2~6개로 불규칙하게 나눔(긴 쪽 38~62% 지점), 12%는 공원(7%)이나 주차장(5%) |
| 건물 모양 | 상자 하나 | 상자, 기단 위 탑(podium), 계단식(3단), ㄱ자, 고층 탑(꼭대기 설비층, 랜드마크 최대 약 215 m) |
| 높이 | 블록 거리별 범위 | 거리 x 모양별 범위, 가까운 블록 9~40 m(데이터센터를 가리지 않음), 먼 곳 최대 170 m와 랜드마크 |
| 외벽 | 창 무늬 한 가지 | 5종: 유리 커튼월, 띠창 사무동, 콘크리트(들어간 창), 벽돌, 금속 핀. 모양에 따라 확률로 고름 |
| 지붕 | 평평한 상자 | 옥상 설비 상자 1~3개, 90 m가 넘는 건물은 가끔 안테나, 지붕은 회색 |
| 입체감 | 없음 | 바닥 쪽을 어둡게(건물 아래 그늘 느낌), 건물마다 색조 차이, 창 무늬 위치를 건물마다 달리함 |
| 땅 | 포장 색 하나, 도로 | 인도(2 m 판 무늬), 공원(잔디 무늬), 주차장(주차선), 도로(점선, 가장자리 선), 횡단보도 |
| 거리 | 가로수, 차량 | 가로수(모양과 색 다양), 가로등(저녁에 불 켜짐), 횡단보도 |
| 먼 풍경 | 언덕 | 먼 도시 윤곽 그림(원통에 둘러 붙임, 안개에 묻힘, 저녁에 어두워짐) |
| 화면 효과 | 없음 | 가장자리를 어둡게(비네트), 해 쪽 따뜻한 빛 번짐. 3D 화면 위 카드는 그 위에 둠 |

## 2. 이미지(그림)와 만드는 방법 (`web/viewer/src/citytex.js`)

모든 그림은 브라우저에서 캔버스로 그린다(저장소에 이미지 파일 없음). 건물 외벽 그림은 256x256에 창 4x4칸이고 켜진 창만 담은 발광 그림이 짝으로 있다.

- 외벽 5종: 유리(칸마다 파랑 계열 그라데이션, 하늘이 비치는 줄), 띠창(콘크리트 띠와 유리 띠), 콘크리트(들어간 창과 층 사이 띠), 벽돌(벽돌 줄눈, 창틀), 금속(세로 핀, 가는 창).
- 지붕처럼 무늬가 없는 면은 모든 그림 오른쪽 아래의 흰 점을 가리키게 하고 꼭짓점 색으로 칠한다.
- 지면 그림: 도로, 인도, 잔디, 주차장. 먼 도시 윤곽은 2048x256.
- 건물 크기에 맞게 창이 정수 칸으로 반복되도록 uv를 맞춘다.

## 3. 그리기 부담과 화질

- 건물은 외벽 종류별로 한 덩어리(5개), 지붕 설비 한 덩어리, 인도, 공원, 주차장, 도로, 횡단보도가 각각 한 덩어리라 그리기 호출은 외관에서 약 38개다.
- 화질 단계(`docs/23`)는 그대로 쓴다: 낮음은 블록 5x5, 차량과 가로등 최소, 높음은 7x7과 반사 등. 가로등 수는 가로수 수의 60%다.
- 측정(소프트웨어 렌더링, 단계 비교용): 외관 높음 4프레임, 보통 9~12, 낮음 12~19. 이전(23)과 비슷하다. 실제 기기 프레임은 확인하지 못했다.

## 4. 시험

- 단위 시험: 같은 입력이면 같은 배치, 가운데 블록 비움, 모든 상자가 자기 블록 안, 서로 다른 건물의 바닥이 겹치지 않음, 쌓은 상자가 아래 상자 안에 있음, 외벽 5종과 모양 5종과 높이 차이와 공원과 주차장, 이웃한 건물이 같은 모양과 외벽일 비율 30% 미만, 가로등과 횡단보도 수.
- 화면 확인(73개)과 화면 캡처로 낮과 저녁을 눈으로 확인했다.

## 5. 한계와 다음

| 한계 | 설명 |
|---|---|
| 아직 상자 조합이다 | 곡면, 경사 지붕, 발코니 같은 세부는 없다. 외벽 그림이 모양을 대신한다 |
| 건물 그림자 없음 | 도시 건물이 데이터센터에 그림자를 드리우지 않는다 |
| 사람과 신호등 없음 | 거리 소품은 가로등, 가로수, 차량, 횡단보도까지다 |
| 외벽 그림은 반복된다 | 가까이서 보면 같은 창 무늬가 반복된다(건물마다 위치만 다름) |
| 다음 후보 | 건물 그림자, 경사 지붕과 발코니, 신호등과 보행자, 저녁 하늘에 맞춘 외벽 색, 해 방향에 맞춘 유리 반사 |
