# 25. 웹 화면의 UX 구조 정리

- 상태: 채택 (2026-11-03)
- 목적: 화면에 요소가 한꺼번에 몰려 뒤죽박죽이던 것을 "무엇을 어디에서 하는가"가 분명하도록 정리한다.
- 관련: [18 웹 보기](18_web_viewer_spec.md), [24 디자인 시스템 적용](24_web_design_system.md)

## 1. 정리 전 문제

| 곳 | 문제 |
|---|---|
| 상단 | 제목, 뒤로 가기, 상태 표시, 보기 방식, 시나리오 선택, 집계, 도움말이 한 줄에 몰려 있고, 상태 문구가 길면 도움말이 아래 줄로 떨어졌다 |
| 3D 화면 위 | 보기 값(라디오)과 시점 단추(위에서, 비스듬히), 켜고 끄는 단추(통로 이름, 장비 모양, 공기 흐름)가 똑같은 모양의 단추로 섞여 있었다 |
| 오른쪽 패널 | 시나리오 요약, 조작 패널, 선택한 장비, 알람이 위아래로 길게 쌓여, 시뮬레이션 중에는 장비와 알람이 화면 밖으로 밀렸다 |
| 아래 | 재생 막대, 범례, 신뢰 등급 표시 6개, 면책 문구가 세 줄에 걸쳐 있었다 |
| 좁은 화면 | 상단이 화면을 많이 차지했고, 아래쪽 내용이 하단 막대에 가려졌다 |

## 2. 새 구조

```
┌ 상단(한 줄) ───────────────────────────────────────────────────────┐
│ 제목 [← 외관으로]  [녹화 재생|직접 시뮬레이션|로컬 서버]    집계 값  도움말 │
├ 3D 화면 ───────────────────────────────────┬ 오른쪽 패널 ──────────┤
│ 왼쪽 위: 보기 값(알약 3개)                    │ 요약 | 장비 | 조작* | 알람(n) │
│          시점 묶음 / 표시 묶음(켜면 ✓)        │ (한 번에 한 장만 보인다)        │
│ 오른쪽 위: 상태 표시(녹화/시뮬레이션/연결)     │                               │
│ 왼쪽 아래: 색 범례                            │  * 조작 탭은 직접 시뮬레이션과     │
├────────────────────────────────────────────┴ 로컬 서버일 때만 나타난다 ──┤
│ 재생 막대(재생, 속도, 시간 막대, 반복) + 한 줄 면책 문구                         │
└───────────────────────────────────────────────────────────────────┘
```

| 결정 | 이유 |
|---|---|
| 시나리오 선택을 "요약" 탭으로 옮김 | 시나리오 설명과 한 곳에 있어야 읽기 쉽다. 상단에서는 "어떻게 보는가"(보기 방식)만 고른다 |
| 상태 표시를 3D 화면 오른쪽 위로 옮기고 문구를 줄임(예: "직접 시뮬레이션 · 간이 모델") | 상단이 길어지지 않는다. 자세한 설명은 조작 탭에 이미 있다 |
| 보기 값을 알약 묶음 하나로, 시점과 표시를 이름 붙은 두 묶음으로 나눔 | "하나만 고르는 것", "시점 이동", "켜고 끄기"는 쓰임이 달라 모양도 달라야 한다. 켜고 끄는 단추는 켜지면 ✓가 붙는다 |
| 범례를 3D 화면 왼쪽 아래로 옮김 | 색을 읽는 곳 가까이에 둔다. 신뢰 등급과 알람 테두리의 뜻은 도움말에 있고, 장비를 고르면 상세에 나온다 |
| 오른쪽 패널을 탭으로 나눔 | 한 번에 한 가지만 보여 스크롤이 줄고, 알람 개수는 탭에 붙여 항상 보인다 |
| 장비를 고르면 "장비" 탭이 열리고, 선택을 풀면 요약으로 돌아감 | 3D에서 고른 결과를 바로 보여 준다. 조작 중에는 조작 탭에 머문다(선택한 랙 슬라이더가 거기 있음) |
| 조작 탭은 시뮬레이션과 서버일 때만 나타나 열림 | 녹화 재생에서는 쓸 수 없는 것을 보여 주지 않는다 |
| 탭은 좌우 화살표로 이동, 역할과 연결(`tablist`, `tab`, `tabpanel`, `aria-selected`) | 키보드와 화면 읽기 프로그램 |
| 좁은 화면: 상단은 제목+도움말, 보기 방식(가로로 밀어 보기), 집계의 세 줄. 페이지가 자연스럽게 세로로 스크롤되고, 3D 화면 위 단추 묶음은 가로로 밀어 본다 | 3D 화면과 패널이 하단 막대에 가려지던 문제 해결 |

## 3. 확인

- 화면 확인 73개 통과(UX 구조 10개 추가: 탭 구성과 자동 전환, 조작 탭 나타남과 사라짐, 키보드 이동, 상단 높이 64px 이하, 범례와 상태 표시 위치, 390px 폭에서 상단 150px 이하와 가로 스크롤 없음).
- 확인하지 못한 것: 사용자 시험(실제 사용자가 길을 찾는지), 화면 읽기 프로그램 전체 점검, 실제 모바일 기기.
