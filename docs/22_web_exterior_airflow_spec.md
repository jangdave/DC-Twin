# 22. 웹 외관 환경과 공기 흐름

- 상태: 채택 (2026-11-03)
- 목적: 웹 보기 화면의 외관을 Unreal 외관처럼(실제 건물 모양, 옥외 설비, 하늘, 땅) 보이게 하고, 홀 안 공기 흐름을 움직임으로 보여 준다.
- 관련: [12 Unreal 설계](12_unreal_design.md) 12.3~4장, [14 시뮬레이션에서 Unreal로](14_sim_to_unreal_core.md), [15 외관 참고 조사](15_exterior_references.md), [18 웹 보기](18_web_viewer_spec.md), [21 웹 시뮬레이션](21_web_simulation_spec.md)
- 표기: 공기 흐름은 **시각화 목적**이다. 실제 계산 결과가 아니고 공학적 정확성을 주장하지 않는다.

## 1. 외관 환경

| 요소 | 방법 | 파일 |
|---|---|---|
| 건물과 옥외 설비 | `building_exterior.blend`를 glb로 내보낸다. 메시는 Draco로 압축하고, 콘크리트, 외벽 패널, 지붕, 아스팔트 4종은 기본색 그림만 1K(1024)로 줄여 넣는다(1.5 MB, gzip 약 700 KB). 재질별로 합쳐 그리기 호출을 16개로 줄인다 | `blender/scripts/export_building_glb.py`, `web/viewer/public/models/building.glb` |
| 하늘, 구름, 해 | 하늘 구면에 색 곡선과 잡음 구름을 코드로 그린다 | `web/viewer/src/env.js` |
| 지평선 | 링 모양 땅을 잡음으로 올린 먼 언덕 | 같음 |
| 땅과 그림자 | 풀밭 원판. 해 빛에서 그림자 지도(4096)를 만든다 | `scene.js` |
| 시간대 | 낮(기본), 저녁(`?sky=dusk` 또는 외관 카드의 "저녁으로 보기" 단추) | `SKY_PRESETS` |

- 텍스처(4K 원본 약 230 MB)는 원본을 올리지 않는다. 기본색 한 장만 1K로 줄여 넣고, 거칠기와 금속 지도는 버려 재질별로 정한 값을 쓴다. 콘크리트와 외벽 패널은 법선 지도(1K)도 남겨 요철을 살린다. 그래도 Unreal보다는 약하다.
- Draco 압축 해제기(`public/draco/`, three.js 예제 폴더에서 복사)를 같이 올린다. 해제기가 작업자(worker)와 wasm을 쓰므로 `index.html`의 보안 정책(CSP)에 `worker-src 'self' blob:`, `'wasm-unsafe-eval'`, 그리고 `blob:` 이미지와 연결을 추가했다(모두 같은 출처가 만든 blob이다).
- 모델을 받기 전과 실패했을 때는 이전 상자 건물을 그대로 쓴다. 클릭 판정은 건물 크기의 보이지 않는 상자로 한다(건물 모델은 삼각형 약 16만 개).
- 홀 단계에서는 하늘과 안개를 끄고 홀 조명만 켠다.

## 2. 공기 흐름

- 데이터: `hall60_sim.py`의 질량 보존 퍼텐셜 흐름(점성, 난류, 부력 없음)을 홀 장면에서 계산한다. 정상 가동 1개와 CRAC 1대씩 멈춘 8개를 20 cm 격자(55×68×20)로 줄여 int8로 저장한다(`flow.bin` 약 2 MB, gzip 237 KB). 만드는 법: `experiments/omniverse_probe`에서 `uv run --python 3.13 python export_web_flow.py`.
- 겹치기: 속도 = 정상 + Σ (1 − 팬 비율) × (그 CRAC이 멈춘 장 − 정상). 팬을 일부만 줄이면 그만큼만 반영하는 **근사**다. 같은 통로의 CRAC가 둘 다 멈추는 경우 등은 정확한 풀이와 다르다.
- 입자: 7,000개를 급기구에서 띄워 속도장을 따라 흘린다. 흐름 방향이 보이게 짧은 선(꼬리 0.4초)으로 그리고, 화면 속도는 2.2 m/s로 자른다. 랙을 지난 입자는 그 랙의 **배기 온도 색**(호박색 → 빨강), 지나기 전은 가까운 랙 4대의 **입구 온도 색 평균**(거리 역수 제곱 가중, 그림 위 칸 단위로 미리 계산)(18도 파랑 → 35도 빨강, 밝게)이다.
- 반응: CRAC 팬 속도 센서 값(녹화, 직접 시뮬레이션, 로컬 서버 모두)이 바뀌면 속도장을 다시 겹친다. 통로 하나가 멈추면 지붕 틈으로 새는 흐름이 생긴다(`leak` 9.6 m³/s).
- 끄기: "공기 흐름" 단추. 속도장을 받지 못하면 단추를 숨기고 흐름 없이 쓴다.

## 3. 용량 기준

- 첫 로딩(모델과 속도장 제외): 1.5 MB 이하(약 505 KB, Draco 해제기 포함).
- 화면이 뜬 뒤 받는 모델과 속도장까지 합쳐 3 MB 이하(약 1.5 MB).

## 4. 한계와 다음

| 한계 | 설명 |
|---|---|
| 흐름은 정해 둔 규칙에 가깝다 | 퍼텐셜 흐름이라 소용돌이와 부력이 없다. OpenFOAM과 비교하지 않았다 |
| 팬 일부 조절은 근사 | 위 2장 |
| 외관 질감 | 기본색 1K에 법선 지도(콘크리트, 외벽 패널만). 거칠기 지도가 없어 Unreal보다 평평해 보인다 |
| 시간 변화 | 속도장은 정상 상태이고 시간에 따라 변하지 않는다(팬 상태에만 반응). 열기 일렁임은 없다 |
| 다음 후보 | 입구 온도를 열 이동을 계산한 온도장으로 만들어 입자 색에 연동(지금은 가까운 랙 값을 거리로 섞은 것이라 물리 계산이 아니다) |
