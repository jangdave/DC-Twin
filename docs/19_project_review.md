## 4. 낮음

- **Unreal**: 깨진 `ts`가 최신으로 인정됨(L1), 클라이언트가 `unit`, `range`를 검사하지 않음(게이트웨이 신뢰), 매니페스트 중복 센서 ID 미거부, 재시도마다 상태 깜빡임과 백오프 무력화, 연결 중 소켓 정리 때 `Close()` 미호출(추정), 소켓이 조용히 멈추는 경우 감시 없음, 메시지마다 할당(측정 전), 색 값의 색 공간(눈으로 보고 정할 것). 시험에 빠진 것: 시각 되감기, 끊김 알림, 알람 오타, 색 정지점 정확값, 연결과 재접속, 오버레이.
- **센서 생성기와 대리 모델**: 가까운 제거 랙 판정이 접힌 좌표를 써서 줄 양쪽을 모두 가깝다고 봄(`residual_model.py:108`), 앞면 방향을 y로 가정, 우리 솔버와 OpenFOAM의 센서 읽기 방식 차이(삼선형 보간 대 칸 내림)가 잔차에 섞임, 우리 솔버의 "정상 상태" 값이 실제로 정상 상태인지 미확인(추정), `progress.json`의 `test_B` 항목 때문에 개수 서술이 어긋남, E5 5장의 "불확실성 추정 없음"이 8장과 모순, L2의 구간이 잡음이 더해진 값이 아니라 모델값 기준임을 문서에 적을 것.
- **게이트웨이**: `--record` 스트림의 오류·종료 처리 없음과 입력 파일 덮어쓰기 위험, ping/pong 없음, 재생 때 큰 시각 간격 대기, 첫 샘플의 미래 시각 검사 없음, 문서의 시험 개수 38과 실제 39 불일치.
- **USD 도구**: `Sensor_*` 앵커가 이름 규칙에 걸리지 않음, `--strict`에 해당하는 경고 단계 규칙이 없음, Row 개수와 랙 번호 연속성은 검사하지 않음.
- **저장소 위생**: 회사 프로젝트의 폴더 경로가 추적 파일(`CLAUDE.md`, `.claude/settings.json`, 점검 스킬 설명)에 적혀 있다(금지어에는 안 걸리나 폴더 이름이 공개됨, 공개 여부는 소유자가 정한다). 커밋 3건의 작성자가 개인 이메일이다(나머지 36건은 noreply, 직접 확인). 시험 결과 파일 한 곳에 사용자 폴더가 든 절대 경로가 있다. 추적되지 않는 `experiments/omniverse_probe/out/whatif/`, `expand.log`, `unreal/DataCenter_DT/Content/UsdAssets/`는 올릴지 정해야 한다. 외부 에셋 라이선스 표(`ASSET_LICENSES.md`)는 어긋남 없음.
- **문서**: 용어집의 금지 표현("스모크 테스트", "클린룸 점검")이 `p1_ovrtx_smoke` 스크립트 첫 줄과 점검 스킬 제목에 남아 있다(폴더 이름은 두고 설명 문구만 맞춘다). 환경 점검일이 2026-10-15라 오래됨. `docs/11` 8장 보안에 웹 보기 화면의 라이브 모드 한 줄이 필요하다.

## 5. 웹 보기 화면 재점검 결과 (직접)

- 다시 확인한 것: 개발 서버(`npm run dev`)와 CSP가 충돌하지 않음, 빌드 결과가 상대 경로(`./assets`)라 하위 주소 배포가 가능함, 값을 모두 `textContent`로 넣음, 의존성 취약점 0건(`npm audit`).
- 이번에 찾아 고친 것:
  1. 브라우저에서 라이브 재접속이 안 되던 버그(`setTimeout` 호출 방식으로 "Illegal invocation"). 자동 시험에는 가짜 타이머를 끼워서 안 잡혔고 헤드리스 브라우저 확인에서 잡힘. 함수로 감싸 해결.
  2. `stop` 직후 `start`할 때 옛 연결의 늦은 알림이 재접속을 만드는 경쟁 상태. 시험 추가.
  3. 새 시나리오 시작 때 값과 알람 목록을 비우지 않던 문제(H1과 같은 종류). 시험 추가.
  4. 라이브에서 접속 전에 이미 일어난 알람이 목록에 안 보이던 문제. snapshot의 알람 상태에서 채움.
  5. 시나리오 전환 때 일시정지가 풀리던 문제, 시간 막대 밖의 이동에서 알람 목록이 갱신되지 않던 문제.
- 남은 한계: 눈으로 본 확인은 캡처뿐, Firefox와 Safari 미확인, 실제 GPU의 프레임과 메모리 미측정, WebGL 컨텍스트 손실 처리 없음, 재생 중 값 갱신마다 장면 색을 다시 계산함(60기라 문제 없음), `window.__viewer` 점검 훅이 운영 빌드에도 노출됨(읽기 전용 상태이나 배포 때 끌지 정한다).
